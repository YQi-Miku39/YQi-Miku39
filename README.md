## Selected Projects

### Dark Souls III Visual Agent

**Python · PyTorch · Computer Vision · Imitation Learning · Real-Time Control**

A research-style game agent project whose current goal is to defeat Iudex Gundyr from gameplay pixels and real-time virtual input.

The project began with a hybrid baseline that combined RGB behavior cloning with privileged RAM/TAE-assisted supervision and reached approximately a 70% local win rate. The current Phase 2 removes privileged runtime information: visual perception is nearing completion, with behavior cloning as the next major stage.

[View repository →](https://github.com/YQi-Miku39/ds3-visual-agent)

### Chiikawa Merch Tracker

**Python · Playwright · SQLite · Data Engineering · Automation**

A data-collection and normalization project for a future consumer-facing Chiikawa merchandise search app. The current implementation collects and audits Mercari Japan listings while preserving historical observations, status evidence, and provenance.

The longer-term goal is a single search experience across supported marketplaces such as Mercari, Yahoo! Auctions Japan, eBay, and Xianyu, with normalized listings, price history, and direct links back to the source marketplace.

[View repository →](https://github.com/YQi-Miku39/chiikawa-merch-tracker)
